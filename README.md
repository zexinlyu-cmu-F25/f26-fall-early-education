# KidDash — Landing Page

NFC-enabled, real-time student pickup coordination for elementary schools.

Warm, illustrated, interactive landing page: a clickable school scene, a sticky-note board you can clear, and a playable pickup where you drag the child to the right parent.

## Develop

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # output in dist/
```

Stack: Vite 6 + React 19 + Tailwind CSS 4. Page sections live in `src/components/`.
